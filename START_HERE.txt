GoalOS 2026 — Stay Connected to Google Sheets

1. Extract the ZIP.
2. Upload ALL extracted files to the ROOT of your existing GitHub Pages repository.
3. Wait for Pages deployment, then Ctrl + Shift + R on the live site.
4. Open GoalOS Settings → Resume/Connect Google Sheets, then link your EXISTING Sheet if needed. DO NOT create another Sheet when you already have data in one.
5. Check the status Saved to Sheets, then refresh the same tab to test persistence.
6. To use a different phone or PC, choose Copy link for another device and authorize Google there once.
7. Disconnect this device only when you choose.

Google's short-lived OAuth tokens cannot stay valid forever on a static website. If one expires, use Resume Google Sheets. No Google Drive backup, no Gmail reminders.
