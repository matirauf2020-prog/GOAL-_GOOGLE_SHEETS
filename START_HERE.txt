GOALOS — GOOGLE SHEETS CLOUD RESTORE EDITION

1. Extract all files in this folder into the ROOT of your GitHub Pages repository.
2. Commit and wait for GitHub Pages to deploy.
3. Open your GitHub Pages website and press Ctrl+Shift+R once.
4. The GoalOS welcome screen appears before the dashboard.
5. Connect Google. If a Sheet is already linked, GoalOS checks it and restores the cloud workspace if the local copy is missing.
6. If no Sheet is linked, go to Settings & Google Sheets and create/select your private Sheet.
7. Bookmark the URL after linking. It includes a non-secret Sheet ID recovery pointer.

Important:
- Keep your Google Sheet sharing set to Restricted.
- Only the OAuth Web Client ID belongs in site-config.js / the public page. Never upload a client secret or OAuth JSON file.
- No Google Drive API, Gmail, reminders, or Apps Script are used.
- If local/cloud data differ, GoalOS stops and asks you to resolve the conflict.
- A Google access token can expire; Google may require you to reconnect.
- Never upload your private JSON backup or Excel workbook to a public GitHub repository.

See SETUP_SHEETS.md for the complete Google Cloud and recovery instructions.
