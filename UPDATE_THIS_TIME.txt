GOALOS STARTUP + GOOGLE SHEETS RESTORE UPDATE

This is a full website update. Replace the existing website files in the GitHub Pages repository root with the files from this package.

Main changes:
- Startup welcome screen is always shown before the dashboard.
- Existing Google session + linked Sheet are checked before opening.
- Missing local workspace data is restored from the linked Google Sheet.
- After a successful restore, GoalOS automatically opens the main workspace.
- Local/cloud conflicts stop for review instead of silently overwriting data.
- The linked Sheet ID is written to the page URL fragment as a recovery pointer. Bookmark that URL.
- Clear local cache preserves the Google Sheet and immediately restores it when currently authorized.
- Service-worker cache version is updated to prevent old app files from being reused.

Do not upload private Excel or JSON data to a public repository. Do not upload the OAuth client secret.
